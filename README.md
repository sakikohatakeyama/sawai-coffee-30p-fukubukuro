# 澤井珈琲ドリップコーヒー オールスターズ30（予約販売・楽天GOLDページ）

※商品名はFV画像の表記「オールスターズ30」に合わせています（予約カード・商品概要・ページタイトル）

30袋ぜんぶ違う珈琲を飲み比べできる、ドリップバッグ30種アソート福袋の特集ページです。

- `index.html` … 本番用ページ（HTML・CSS・JS を1ファイルにまとめています）
- `img/pk-*.webp` … ドリップバッグのパッケージ写真（15銘柄）。公開時は `img/` ごとアップしてください
  - 澤井珈琲の楽天商品ページの画像から、袋が正面・平置きで写っているものを切り抜き
  - マイルド・ライト・ビター … saledripbag（3種ドカン）の画像／やくも・アニバーサリー・モカ・プレミアムゴールド・メロー・夢浪漫 … osechi-sw100set（甘い香り10種）の内容一覧画像／カシオペア・サザンクロス・リッチヨーロピアン … osechirich（香り鮮やか10種）の内容一覧画像／ビタークラシック … bitterclassicdripbag の画像／リッチ・ハロー … dp-richhello50 の画像
  - 残り15銘柄は、正面の写真が見つからない（斜め・手やカップが重なる）ためCSSのイラストで表示
- 動きの参考：https://the-butter.com/ （丸写しはせず、「左右2色に分けたFV」「スクロールで文章がふわっと出る」の雰囲気だけを参考にしています）
- 文字組み：ページ全体に `font-feature-settings:"palt"`（全角かっこ・句読点の余白を詰める。例「日（土）」）
- 日本語：ヒラギノ角ゴ（Mac・iPhone）。ヒラギノがない環境（Windows・Androidなど）は Noto Sans JP（Webフォント）で表示。`:root` の `--jp` で一括変更できます。見出しは太さ800（ヒラギノW8）
  - モリサワのフォント（UD新ゴなど）を使う場合は、モリサワのWebフォント（TypeSquare など）の契約が必要です
- 数字・英字：Jost（Webフォント）。文章中の数字・英字もJostで表示。`:root` の `--num`（大きな数字）と `--jp`（本文の先頭）で変更できます

## 構成
0. **PCのFVは画像（仮）＋流れるドリップバッグ**：背景は `img/fv-pc.jpg`（2500×1200。「澤井珈琲30」フォルダの「PC_澤井珈琲30種FV.jpg」をそのままコピー（ドリップバッグ表記版）。再圧縮なし。発売日11月15日／オールスターズ30／予約販売限定価格2,250円 税込 送料無料／さらにポイント2倍／予約受付期間）。左の2列（画像の x=45〜175・199〜328 の位置）に30種のドリップバッグを縦に流す（左列は上へ、右列は下へ。写真のない銘柄はイラスト）。画像を差し替えるときは同じファイル名で上書き（列の位置を変える場合は `.fv-col` の left / width）。スマホ（768px以下）は動くFVを表示

1. **スマホのFV（768px以下）**：背景は `img/fv-sp.jpg`（1500×2063。デスクトップ「澤井珈琲30」フォルダの「スマホFV.jpg」をそのままコピー）。画像の y=1252〜1593 と y=1622〜1963 の位置に、30種のドリップバッグが横に流れる2列（上の列は左へ、下の列は右へ）。右下にコーヒーカップ `img/fv-sp-cup.webp`（「スマホFVコーヒー画像.png」をwebp化。幅は画面の約51%、右と下は少しはみ出す）を袋の列の上に重ねる。位置は「スマホFVイメージ.jpg」に合わせて％指定（`.fv-row` `.fv-sp-cup`）
3. 大きな「30 DAYS, 30 COFFEES!」（1文字ずつ跳ねて出てくる）→「同じ一杯は、ひとつもない。」→ 福袋の演出（赤い角丸の枠の中。スクロールで見えたら開始：パッケージ写真の袋が1袋ずつ箱に落ちる→30袋そろうと箱が震えてフタが飛び、光の輪＋紙吹雪とともに写真の15袋が箱から扇形に飛び出す。箱は赤いギンガムチェック＋クリームのリボンと蝶結び、フタは赤の水玉。箱の下（赤い枠の中）に「0 / 30 袋」のカウント、30袋そろうと黄色（#ffe544）の大きな「ALL STARS 30」を箱の下に重ねて表示。箱をタップでもう一度）→ メッセージ本文
4. ご予約のご案内（赤いストライプ地に「ドリップバッグ30袋入り／ご予約受付中！（大きく）」→ カウントダウン → 白いカード）。カウントダウンは日本時間で、10/24 00:00より前は「予約受付開始まで」、受付中は「ご予約特典終了まで（11/15 10:00）」、終了後は「ご予約受付は終了しました」と自動で切り替わる（日時は index.html の START / END で変更）：予約受付中バッジ、商品名、予約販売限定価格 2,250円（税込）、送料無料・ポイント2倍、内容・予約受付期間・発売日の一覧、予約ボタン

5. **LINE UP**：30種のカード。タップするとポップアップが開き、大きなパッケージ・番号・味わいの特長・タグ・単品ページへのリンクを表示。「前の銘柄／次の銘柄」（キーボードの←→も可）で順に見られる。×・背景タップ・Escで閉じる。味わいタイプで絞り込むと、ポップアップの前後もその中だけを回る
7. **本日の澤井珈琲おすすめ**（背景は青 #204ac4）：左に「本日の澤井珈琲おすすめ商品」（スマホは中央揃え・2行）、右にカード。「本日のおすすめを見る」で袋・番号・銘柄名が高速で切り替わり、止まると本日のおすすめ（袋＋番号＋銘柄名＋味わい）を表示。**銘柄は日本時間の日付で決まる**ので、その日はだれが見ても同じ。毎日0時に切り替わり、30種を決まった順（`todayPick()` の並べ替え）に1日1種ずつ回すため、30日間は同じ銘柄が出ない。表示後はボタンが「この銘柄を詳しく見る」に変わり、押すとポップアップが開く

## 大きな画面での表示
デスクトップ（1920px など）でも大きくなりすぎないよう、文字や数字は画面幅に合わせて大きくなる上限を決めています。メインの幅は1040px（`:root` の `--cw`）、最初の画面は高さ最大820px。

## 30種のデータ
`index.html` 下部の `const coffees=[...]` にまとめています（銘柄名・タイプ・袋の色・タグ・味わい文・単品ページID）。
味わいの文章は、ご提供の「ドリップリスト - 商材.pdf」に載っている各商品ページ（item.rakuten.co.jp/sawaicoffee-tea/〜、2026年10月7日に確認）の説明文を要約したものです。

| タイプ | 銘柄 |
|---|---|
| A まろやか・やさしい（8） | マイルド／ライト／アニバーサリー／フォルテシモ／メロー／ハーモニー／氷温甘熟／ハロー |
| B 香り華やか・フルーティー（9） | やくも／モカ／キリマンジャロ／プレミアムゴールド／ソル／テルス／カシオペア／サザンクロス／星ロマン |
| C バランス・コク（6） | 夢浪漫／ビタークラシック／ビターゴールド／ビジネス／豆太／リッチ |
| D しっかりビター（7） | ビター／濃い味／ビクトリー／リッチヨーロピアン／ハウス／オフィス／ルナ |

タイプ分けは商品ページの説明（焙煎度・苦味・香りの表現）をもとにこちらで分類したものです。違和感があれば `cat:'a'〜'd'` を書き換えてください。

### 確認が必要な点
- **メローブレンド**：単品ページがなく、「甘い香り100P」セットのページにも産地（ホンジュラス・ウガンダほか）と「甘い香り・まろやか」程度の情報しかないため、説明は短めです
- **ビクトリーブレンド**：「ブレンドフォルテシモ・ビクトリーブレンド」セットのページで、2種の説明がはっきり分かれていないため、「深煎りの濃厚なコク」という確実な部分だけを書いています
- **プレミアムゴールド**：単品ページは「キューバ産」、甘い香りセットのページは「エチオピア他」と産地の記載が食い違っているため、産地は載せていません
- **袋のイラスト**（写真のない15銘柄）：CSSで描いたイメージで、色も実際のパッケージとは異なります。正面のパッケージ写真をいただければ `coffees` の `img` に追加して差し替えられます

## 公開前に差し替える箇所（黄色の背景で「◯」表示になっています）
- **価格は確定済み**：予約限定価格 2,250円（税込）送料無料
- **予約受付期間・発売日は確定済み**：予約受付 10月24日（土）00:00〜11月15日（日）10:00／発売日 11月15日（日）／さらにポイント2倍
- **（旧）予約期間・発送予定は2か所**：メッセージ下の「ご予約のご案内」カードと、ページ下部の「商品概要」
- **予約期間・発送予定**：`<!-- ▼ 発送予定・予約期間 -->` のコメント下
- **購入URL**：`<!-- ▼ 購入URL -->` のコメントが2か所（ヘッダーのボタン・商品概要のボタン `id="buy"`）。今は `#spec`／`#` になっています。スマホ下部の固定ボタン・FVの「予約する」は商品概要へ移動します
- 差し替え後、`.tbd`（黄色い背景）のクラスを外してください
